Predictive Modeling Using Machine Learning¶

Internship Task 2 — Data Science Domain

Goal: Build models to predict an outcome from data, train/test them for accuracy, and visualize performance with confusion matrices and ROC curves.

Problem: Predict whether a breast tumor is malignant or benign from cell-nucleus measurements (Breast Cancer Wisconsin dataset, 569 samples, 30 features — bundled with scikit-learn).

Algorithms compared: Logistic Regression, Decision Tree, Random Forest.

4. Build & Train Models¶

Logistic Regression is scale-sensitive, so it gets a StandardScaler in a pipeline. Tree-based models don't need scaling.

In [6]:
models = {
    'Logistic Regression': Pipeline([('scaler', StandardScaler()),
                                     ('clf', LogisticRegression(max_iter=1000, random_state=RANDOM_STATE))]),
    'Decision Tree': DecisionTreeClassifier(max_depth=5, random_state=RANDOM_STATE),
    'Random Forest': RandomForestClassifier(n_estimators=200, random_state=RANDOM_STATE),
}

for name, model in models.items():
    model.fit(X_train, y_train)
    print(f"Trained: {name}")

8. Hyperparameter Tuning (Random Forest)¶

In [12]:
param_grid = {
    'n_estimators': [100, 200, 300],
    'max_depth': [None, 5, 10],
    'min_samples_split': [2, 5],
}
grid = GridSearchCV(RandomForestClassifier(random_state=RANDOM_STATE),
                    param_grid, cv=5, scoring='f1', n_jobs=-1)
grid.fit(X_train, y_train)

print("Best parameters:", grid.best_params_)
print("Best CV F1:", round(grid.best_score_, 4))

best_rf = grid.best_estimator_
pred = best_rf.predict(X_test)
print("\nTuned Random Forest — test performance")
print(classification_report(y_test, pred, target_names=['Malignant','Benign']))

11. Conclusion¶

  • Logistic Regression performed best on the test set (accuracy 98.25%, ROC-AUC 0.995), followed by Random Forest (95.6%, AUC 0.993) and the single Decision Tree (92.1%, AUC 0.916).
  • The 5-fold cross-validation ranking is the same (LR 98.1%, RF 95.8%, DT 91.9%), so the result is not a lucky split.
  • The Random Forest beats the single tree because it averages many trees, which reduces overfitting. The tree is still the most interpretable.
  • Tuning the Random Forest (GridSearchCV) gave a best CV F1 of about 0.968 and did not change the overall ranking.
  • ROC curves for Logistic Regression and Random Forest hug the top-left corner (AUC above 0.99), so the classes are well separated by these features.
  • The Random Forest relies most on size and shape measurements: worst perimeter, worst radius, worst concave points, worst area and mean concave points.

Limitations: this is a small, clean benchmark dataset with a single test split of 114 samples. Real clinical use would need larger, more varied data, calibration and expert validation.
